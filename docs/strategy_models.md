# 마케팅 전략 모델: K리그 구단 형태별 서포터즈 유치·팬덤 활성화 6대 벤치마킹 모델

관중 분석 결과와 국내외 구단 사례를 묶어 구단 형태별 제안을 만들기 위한 전략 요약입니다. (2026-11-02 개정)

- 각 모델의 근거는 두 가지입니다. ① 우리 관중 데이터 분석 결과 ② 국내외 구단의 실행 사례와 성과
- **사례의 상세 내용·성과 수치·출처·검증 상태는 [benchmark_cases.md](benchmark_cases.md)에서만 관리합니다.** 이 문서에는 대표 사례 이름만 적습니다.
- 자료 찾는 곳과 검색어: [research/search_guide.md](../research/search_guide.md)

## 1. 인프라 및 대중성 혁신 모델 (The Stadium Experience)

- **개념:** 전용구장 인프라와 진입 장벽이 낮은 대중적 응원 문화를 결합해 라이트 관중을 서포터로 흡수한다.
- **대표 사례:** 대구 FC (K리그1) / 포틀랜드 팀버스 (MLS) → [사례·근거](benchmark_cases.md#1-인프라-및-대중성-혁신-모델-the-stadium-experience)
- **우리 데이터의 근거:**
  - 대구 홈경기는 2023~2025 매 시즌 7~11경기가 12,100~12,300명대에서 멈춤 (수요가 좌석을 넘음, `sellout_proxy`)
  - 시즌 첫 홈경기 +77% (새 관중이 오는 경기)
  - 경기 시간 비 −26%, 평일 공휴일 +48% (관람 환경·일정의 영향)
- **데이터로 확인 못 한 것:** 경기장 시설·좌석 거리·접근성, 응원 문화

## 2. 디지털 멤버십 및 콘텐츠 락인 모델 (Digital Lock-in)

- **개념:** 예매 권한, 전용 콘텐츠 같은 디지털 인프라를 상품화해 팬덤을 유료 회원으로 묶고 고정 서포터층을 확보한다.
- **대표 사례:** 울산 HD (K리그1) / 맨체스터 시티 (EPL) → [사례·근거](benchmark_cases.md#2-디지털-멤버십-및-콘텐츠-락인-모델-digital-lock-in)
- **우리 데이터의 근거:**
  - 시즌 첫 홈경기 +77% (새로 온 관중을 회원으로 바꿀 기회)
  - 파이널 라운드 −18% (시즌 막판 이탈)
  - 주말이 평일보다 +52% (평일 관람 동기 부족)
- **데이터로 확인 못 한 것:** 멤버십 가입 여부, 신규·재방문 관중 구분

## 3. 가성비 스타 마케팅 및 서포터즈 연대 모델 (Strategic Star Marketing)

- **개념:** 초특급 스타 영입이 어려운 리그 환경에서, 화제성과 스토리가 확실한 스타로 파편화된 팬덤을 구단 공식 서포터즈 연합으로 묶는다.
- **대표 사례:** FC 서울 (K리그1) / 인터 마이애미 (MLS) → [사례·근거](benchmark_cases.md#3-가성비-스타-마케팅-및-서포터즈-연대-모델-strategic-star-marketing)
- **우리 데이터의 근거:**
  - 서울 2024 홈 관중 합계 501,091명, 평균 27,838명 (2023 평균 22,633명)
  - 원정 팬이 많은 상대와의 경기 +16%
- **데이터로 확인 못 한 것:** 스타 선수 출전 여부. 우리 모형에 없는 변수라 스타 효과를 따로 추정하지 못했다 (`limitations.md` 3번).

## 4. 전술적 아이덴티티 및 스토리텔링 모델 (Tactical Identity)

- **개념:** 막강한 재정이나 스타 없이, 구단만의 독창적인 전술 철학과 감독·선수의 성장 스토리로 서포터의 자부심을 자극한다.
- **대표 사례:** 광주 FC (K리그1) / 아탈란타 (세리에A) → [사례·근거](benchmark_cases.md#4-전술적-아이덴티티-및-스토리텔링-모델-tactical-identity)
- **우리 데이터의 근거:** 홈팀 최근 5경기 경기당 승점 +1점당 관중 +7%
- **데이터로 확인 못 한 것:** 전술 스타일, 경기 내용의 재미

## 5. 역사적 서사 및 헤리티지 모델 (Historical Heritage)

- **개념:** 연고 이전, 구단 해체 같은 역사적 상처를 '우리가 구단의 정통성을 지킨다'는 명분으로 바꿔 무너지지 않는 코어 팬덤을 만든다.
- **대표 사례:** 부천 FC 1995 (K리그2→K리그1) / AFC 윔블던 (잉글랜드) → [사례·근거](benchmark_cases.md#5-역사적-서사-및-헤리티지-모델-historical-heritage)
- **우리 데이터의 근거:**
  - 부천 2026 K리그1 승격 뒤 평균 관중 +82%
  - 강등 구단 수원의 K리그2 관중은 성적과 거의 무관 (승점 +1점당 +2%)
- **데이터로 확인 못 한 것:** 팬 결속력·소속감 (설문 같은 다른 자료가 필요)

## 6. 생활 밀착형 로컬리즘 및 CSR 모델 (Hyper-Localism)

- **개념:** 축구장을 '지역민의 생활 커뮤니티 광장'으로 정의하고, 서포터를 지역 문제를 함께 푸는 파트너(로컬 크리에이터)로 격상시킨다.
- **대표 사례:** 페르세바야 수라바야 (인도네시아) / 알비렉스 니가타 (J리그), 베르더 브레멘 (분데스리가) → [사례·근거](benchmark_cases.md#6-생활-밀착형-로컬리즘-및-csr-모델-hyper-localism)
- **우리 데이터의 근거:**
  - 더비 +29% (지역 라이벌 구도)
  - 수원 강등 뒤 관중 회복 (2026년 2023년 대비 +36%)
  - 승격 시민구단 관중 증가 (부천 +82%, 안양 +45%)
- **데이터로 확인 못 한 것:** 지역 소속감, 구단의 지역 활동(CSR) 내역
