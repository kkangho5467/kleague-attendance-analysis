# 마케팅 전략 모델: K리그 구단 형태별 서포터즈 유치·팬덤 활성화 6대 벤치마킹 모델

관중 분석 결과와 국내외 구단 사례를 묶어 구단 유형별 제안을 만들기 위한 틀입니다. (2026-11-02 개정: 6대 모델로 교체)

- 각 모델의 근거는 두 가지입니다. ① 우리 관중 데이터 분석 결과 ② 국내외 구단의 실행 사례와 성과
- **아래 사례·성과 수치는 아직 출처를 확인하지 않은 초안입니다.** 포트폴리오에 쓰기 전에 각 항목의 출처(기사·구단 발표·논문)를 찾아 `research/`에 정리하고, 아래 '검증 상태'를 바꿉니다.
- 우리 관중 데이터(2023~2026)로 확인할 수 있는 수치는 직접 대조해 결과를 적었습니다.
- 자료 찾는 곳과 검색어: [research/search_guide.md](../research/search_guide.md) / 사례 수집 양식: [benchmark_cases.md](benchmark_cases.md)

**검증 상태 표시:** ✅ 확인됨(출처 또는 우리 데이터) · ⚠️ 우리 데이터와 맞지 않음 · ⬜ 출처 확인 필요

## 1. 인프라 및 대중성 혁신 모델 (The Stadium Experience)

**개념:** 전용구장 인프라와 진입 장벽이 낮은 대중적 응원 문화를 결합해 라이트 관중을 서포터로 흡수하는 모델.

**국내: 대구 FC (K리그1)**
| 내용 | 검증 상태 |
| --- | --- |
| 전용구장(DGB대구은행파크) 이전 후 평균 관중 3배 증가 (3,518명 → 10,734명) | ⬜ 2018→2019 수치로 보임. 우리 데이터 기간(2023~) 밖이라 연맹 기록·기사로 확인 필요 |
| 이전 당해 시즌 홈경기 9회 매진 | ⬜ 출처 확인 필요 |
| 필드와 7m 거리의 스탠드, '쿵쿵골(발구르기)' 응원의 대중화 | ⬜ 출처 확인 필요 |
| (우리 데이터) 2023~2025 대구 홈경기는 관중이 12,100~12,300명대에서 반복해서 멈춤 → 수요가 좌석을 넘는 경기장 | ✅ `sellout_proxy` (매 시즌 7~11경기) |

**해외: 포틀랜드 팀버스 (미국 MLS)**
| 내용 | 검증 상태 |
| --- | --- |
| 골 세리머니 때 마스코트가 실제 통나무를 자르는 퍼포먼스, 대형 통천 응원으로 직관을 지역 축제로 브랜드화 | ⬜ 출처 확인 필요 (성과 수치도 함께 찾기) |

**우리 분석과의 연결:** 대구의 매진 반복(수요 > 좌석), 시즌 첫 홈경기 +77%(신규 관중 유입 기회), 경기 시간 비 −26%(관람 환경의 영향)

## 2. 디지털 멤버십 및 콘텐츠 락인 모델 (Digital Lock-in)

**개념:** 예매 권한, 전용 콘텐츠 등 디지털 인프라를 상품화해 팬덤을 유료 회원으로 묶고 안정적인 고정 서포터층을 확보하는 모델.

**국내: 울산 HD FC (K리그1)**
| 내용 | 검증 상태 |
| --- | --- |
| K리그 최초 유료 멤버십 등급제 도입, 연간 수만 명의 고정 결제 팬덤 | ⬜ '최초' 여부와 회원 수 출처 확인 필요 |
| K리그 유료 관중 종합 1위 유지 | ⚠️ 우리 데이터에서는 2023~2026 매 시즌 서울의 평균 관중이 울산보다 많음 (예: 2024 서울 27,838명, 울산 18,611명). 기준(특정 시즌, 누적 등)을 확인하거나 문구를 바꿔야 함 |
| '선예매 권한' 기반 멤버십, 자체 다큐멘터리 '푸른 파도' 등 뉴미디어 콘텐츠 | ⬜ 콘텐츠 이름과 내용 출처 확인 필요 |

**해외: 맨체스터 시티 FC (잉글랜드 EPL)**
| 내용 | 검증 상태 |
| --- | --- |
| 글로벌 디지털 멤버십 'Cityzens' 운영, 회원 전용 비하인드 콘텐츠 | ⬜ 출처 확인 필요 |
| 구단 의사결정 투표권 제공 | ⬜ 실제 범위(예: 일부 투표 이벤트인지) 확인 필요 |

**우리 분석과의 연결:** 시즌 첫 홈경기 +77%(새로 온 관중을 회원으로 전환할 기회), 파이널 라운드 −18%(시즌 막판 이탈 방지), 평일 관중이 주말보다 적음(주말 +52%)

## 3. 가성비 스타 마케팅 및 서포터즈 연대 모델 (Strategic Star Marketing)

**개념:** 초특급 스타 영입이 어려운 리그 환경에서, 화제성과 스토리가 확실한 스타로 파편화된 팬덤을 구단 공식 서포터즈 연합으로 묶는 모델.

**국내: FC 서울 (K리그1)**
| 내용 | 검증 상태 |
| --- | --- |
| 제시 린가드 영입 시즌(2024) 총관중 50만 명 돌파 | ✅ 우리 데이터: 2024 홈 관중 합계 501,091명 (정규 리그 18경기) |
| 평균 관중 2만 3천 명 이상 | ⚠️ 2024 평균은 27,838명. 2만 3천 명대는 2023(22,633명)·2025(23,185명) 평균 |
| 단일 시즌 K리그 최초 50만 명 | ⬜ 우리 데이터는 2023년부터라 '최초' 여부는 연맹 기록으로 확인 필요 |
| MD(굿즈) 매출 역대 최고치 | ⬜ 출처 확인 필요 |

**해외: 인터 마이애미 CF (미국 MLS)**
| 내용 | 검증 상태 |
| --- | --- |
| 리오넬 메시 영입 뒤 늘어난 팬덤을 구단 주도의 공식 서포터즈 연합 'La Familia'로 관리 | ⬜ 'La Familia'가 구단이 만든 조직인지, 기존 서포터 그룹인지 확인 필요 |

**우리 분석과의 연결:** 서울 2024 관중 급증. 단, 스타 선수 출전 여부는 우리 모형에 없는 변수라(`limitations.md` 3번) 스타 효과를 따로 추정하지는 못했다.

## 4. 전술적 아이덴티티 및 스토리텔링 모델 (Tactical Identity)

**개념:** 막강한 재정이나 스타 없이, 구단만의 독창적인 전술 철학과 감독·선수의 성장 스토리로 서포터의 자부심을 자극하는 모델.

**국내: 광주 FC (K리그1)**
| 내용 | 검증 상태 |
| --- | --- |
| K리그 최소 수준 예산, 아시아 챔피언스리그(ACL) 무대 돌풍 | ⬜ 예산 순위와 ACL 성적 출처 확인 필요 |
| 소규모 가변석 연일 매진 | ⚠️ 우리 데이터: 전용구장(2023~2024) 최다 관중 8,091명, 매진 반복 패턴 없음. 가변석 등 일부 구역 매진이라면 그 출처가 필요 |
| 이정효 감독의 전술 아이덴티티를 브랜드 자산으로 ("스타는 없지만 우리 팀 축구가 가장 재미있다") | ⬜ 출처 확인 필요 |

**해외: 아탈란타 BC (이탈리아 세리에A)**
| 내용 | 검증 상태 |
| --- | --- |
| 거액 영입 없이 공격 축구 철학과 유스 시스템으로 지역 소도시 주민을 코어 서포터로 결집 | ⬜ 출처와 관중·회원 변화 수치 확인 필요 |

**우리 분석과의 연결:** 홈팀 최근 5경기 경기당 승점 +1점당 관중 +7%. 전술 스타일 자체는 우리 데이터로 측정하지 못했다.

## 5. 역사적 서사 및 헤리티지 모델 (Historical Heritage)

**개념:** 연고 이전, 구단 해체 같은 역사적 상처를 '우리가 구단의 정통성을 지킨다'는 명분으로 바꿔 무너지지 않는 코어 팬덤을 만드는 모델.

**국내: 부천 FC 1995 (K리그2 → 2026 K리그1)**
| 내용 | 검증 상태 |
| --- | --- |
| 연고 이전(부천 SK → 제주)으로 팀을 잃은 서포터들이 돈을 모아 재창단한 서포터 주도형 구단 | ⬜ 창단 과정 출처 확인 필요 (더비 목록의 '연고 이전 더비: 제주–부천'과 연결) |
| 성적과 관계없이 깨지지 않는 코어 결속력 | ⬜ 정량 근거 필요 |
| (우리 데이터) 2026 K리그1 승격 뒤 평균 관중 +82% (3,615명 → 6,563명) | ✅ `03_suwon_case.ipynb` |

**해외: AFC 윔블던 (잉글랜드)**
| 내용 | 검증 상태 |
| --- | --- |
| 강제 연고 이전에 반발한 서포터들이 직접 창단해 9부 리그부터 프로 리그까지 승격 | ⬜ 출처 확인 필요. 현재 소속 리그는 최신 정보로 다시 확인 (자료 초안에는 '리그 투'로 적혀 있음) |

**우리 분석과의 연결:** 부천 승격 후 관중 증가. 강등 구단 수원의 K리그2 관중이 성적과 거의 무관(+2%/승점 1점)했다는 결과도 '성적과 별개인 코어 팬덤'이라는 관점과 이어진다.

## 6. 생활 밀착형 로컬리즘 및 CSR 모델 (Hyper-Localism)

**개념:** 축구장을 '지역민의 생활 커뮤니티 광장'으로 정의하고, 서포터를 지역 문제를 함께 푸는 파트너(로컬 크리에이터)로 격상시키는 모델.

**인도네시아: 페르세바야 수라바야**
| 내용 | 검증 상태 |
| --- | --- |
| '영웅의 도시' 지역 정체성과 팬 커뮤니티 보넥 마니아를 중심에 둔 리브랜딩, 공식 SNS 소통 | ✅ Hidayat 외(2022) → [요약](../research/papers/2022_hidayat_persebaya/summary.md). 단, 성과 수치는 없음 |
| 과격한 훌리건이었던 보넥 마니아를 환경 캠페인·재난 구호 등 지역 사회 해결사로 리브랜딩 | ⚠️ **우리가 번역한 논문에는 나오지 않는 내용.** 다른 출처가 필요 |

**해외: 알비렉스 니가타 (일본 J리그) / SV 베르더 브레멘 (독일 분데스리가)**
| 내용 | 검증 상태 |
| --- | --- |
| 니가타: 지역 마트, 지역 농산물 브랜딩, 로컬 축제와 서포터 활동 결합 ('니가타 시민의 삶 = 알비렉스 서포터') | ⬜ 출처와 관중 수치 확인 필요 (J리그 구단 경영 정보 공개 자료 활용) |
| 브레멘: 팬에게 구단 지배구조(50+1 규정)상 실질적 지분·의사결정권 부여 | ⬜ 50+1 규정은 분데스리가 공통 규정이므로, 브레멘만의 특징이 무엇인지 확인 필요 |

**우리 분석과의 연결:** 더비 +29%(지역 라이벌 구도), 수원 강등 뒤 관중 회복(2026년 2023년 대비 +36%)
