# 벤치마킹 케이스 수집 (전략 모델별)

[strategy_models.md](strategy_models.md)의 6대 전략 모델마다 근거가 될 국내외 구단 사례를 모으는 작업 문서입니다. (2026-11-02 개정: 분석 결과별 → 전략 모델별)

- 분석 결과만으로 만든 제안은 '아이디어'에 그칩니다. 실제 제안은 **다른 구단에서 실행해 효과가 확인된 사례**를 근거로 씁니다. README와 노트북의 제안 표는 이 문서가 채워질 때까지 '예시'로 둡니다.
- 사례의 원문·번역·요약은 [research/](../research/README.md)에, 검색 사이트와 검색어는 [research/search_guide.md](../research/search_guide.md)에 있습니다.
- 사례 초안은 `strategy_models.md`의 내용을 옮긴 것입니다. 출처를 확인하면 '출처' 칸을 채우고 '검증' 칸을 바꿉니다.

## 수집 기준

1. **성과가 숫자로 있는가:** 관중 +○%, 회원 ○명, 시즌권 갱신율 ○% 같은 수치가 있는 사례를 우선합니다. 수치가 없으면 '참고'로 분류합니다.
2. **출처가 믿을 만한가:** 구단·리그 공식 발표 > 언론 기사·학술 논문 > 블로그·SNS. 링크와 확인한 날짜를 꼭 적습니다.
3. **비교 대상이 가까운가:** K리그 > J리그·KBO > 해외 축구·미국 프로스포츠 순으로 그대로 적용하기 쉽습니다.
4. **우리 분석과 이어지는가:** 사례마다 '우리 분석의 어떤 결과와 연결되는지' 한 줄을 적습니다. 연결이 약하면 넣지 않습니다.

**검증 표시:** ✅ 확인됨 · ⚠️ 우리 데이터와 맞지 않음(수정·확인 필요) · ⬜ 출처 확인 필요
