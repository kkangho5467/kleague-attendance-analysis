# 자료수집

마케팅 제안의 근거가 될 외부 자료(논문, 다른 리그·구단 사례)를 모으는 폴더입니다.
어떤 자료를 찾는지와 수집 기준은 [docs/benchmark_cases.md](../docs/benchmark_cases.md)에 있습니다.

## 폴더 구조

```
research/
├── README.md                 # 이 파일: 수집한 자료 목록
├── papers/                   # 논문. 한 편당 폴더 하나 (연도_첫저자_주제)
│   └── 2022_hidayat_persebaya/
│       ├── original.pdf      # 원문 (공개 라이선스인 경우만 넣기)
│       ├── translation_ko.md # 번역 (필요할 때)
│       └── summary.md        # 요약·근거 평가·우리 분석과의 연결
└── cases/                    # 기사·구단 발표 등 실제 실행 사례. 한 건당 파일 하나
```

- **원문을 넣어도 되는지 확인합니다.** CC BY, CC BY-NC 같은 공개 라이선스는 출처를 밝히면 넣을 수 있습니다. 저작권이 있는 유료 논문·기사는 원문 대신 링크와 요약만 남깁니다.
- `summary.md`에는 꼭 **근거로서의 평가**(성과 수치가 있는가, 일반화할 수 있는가)와 **우리 분석의 어떤 결과와 이어지는지**를 적습니다.
